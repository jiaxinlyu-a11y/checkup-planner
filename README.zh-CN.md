# 体检方案规划（Check-up Planner）

[English](README.md) | 中文

一个小型网页工具：按个人情况生成体检方案，而不是默认的医院套餐。输入年龄、性别、身高体重、生活方式、工作环境和（选填的）家族史，它会列出适用的体检项目，并给出每一项的证据等级和出处。页面支持中文和英文。

所有计算都在浏览器里完成，填写的内容不会被发送或保存（只会记住你选的语言）。没有构建步骤，也没有依赖。

## 运行

用浏览器打开 `index.html` 即可。也可以在本地起一个服务：

```
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面：问题表单、结果区、数据来源 |
| `js/rules.js` | 规则逻辑（`RULES`）和参考文献列表（`SRC`） |
| `js/i18n.js` | 中英文的全部显示文字：表单标签、标题、触发理由、详细说明、标签 |
| `js/app.js` | 读取表单、逐条运行规则、绘制匹配的项目、切换语言 |
| `css/style.css` | 布局和配色，浅色和深色跟随系统设置 |

## 一条规则怎么工作

`RULES` 里的每一项是一个体检项目，只放逻辑：

```js
{ id: "hcv", group: 1, level: "guideline", src: ["uspstfAB"],
  check: p => between(p.age, 18, 79) ? { why: "a" } : null }
```

`check` 接收填写的信息，返回 `null`（不适用）或 `{ why, level? }`。`why` 选择该规则的一条触发理由文字；只有当匹配比规则本来的等级更弱时才会返回 `level`，比如这个人超出了指南研究的年龄范围。

文字写在 `js/i18n.js` 里，用同一个 `id`，每种语言各一份：

```js
hcv: { title: "丙肝抗体筛查", tag: "USPSTF B（2020）",
  why: { a: "18 到 79 岁成年人" },
  detail: "USPSTF 推荐对 18 到 79 岁成年人做丙肝筛查。" }
```

新增规则：在 `RULES` 加一项，在 `I18N.en.rules` 和 `I18N.zh.rules` 各加一份文字，新的参考文献加进 `SRC`（中英文各一个名称）。

## 证据等级

- **指南推荐**（4 星）：USPSTF 评为 A 或 B 级，或国内外正式指南明确推荐。
- **共识推荐**（3 星）：专家共识给出的推荐，强度按共识自己的表决比例，不等于正式证据分级。
- **法规要求**（5 星）：职业健康法规或强制性标准的要求（美国 OSHA，国内 GBZ 188—2025）。
- **可考虑**（1 星）：证据较弱，或基于生活习惯的推断。只作为建议显示，不写成“推荐”。
- **不建议常规做**（无星级）：指南、立场声明或综述建议没有症状、也没有已知风险的人不做。这类项目单独放在最后一组，每一项都用一两句话写明是谁、因为什么不建议。目前有九项：甲状腺超声、卵巢癌筛查（CA-125、经阴道超声）、胰腺癌筛查扫描、低风险成年人的心电图、颈动脉超声、慢阻肺肺功能筛查、睾丸检查、肿瘤标志物血检（2026 年的系统综述，不是指南）和全身 CT（2002 年的 ACR 声明）。

星级表示出处的强度，不代表疾病有多严重，也不代表你个人有多需要这项检查。对应关系只有一行，在 `js/app.js` 的 `STARS` 里。

## 数据来源

共 41 条规则，主要来自美国预防服务工作组（USPSTF），同时参考美国癌症协会和美国胃肠病学会的指南、国内指南（2023 血脂指南、2023 宫颈癌筛查指南、2018 肺癌低剂量 CT 筛查指南、2021 家庭幽门螺杆菌共识）、美国 OSHA，以及国内职业健康标准 GBZ 188—2025。完整的参考文献列表在页面底部和 `SRC` 里。中美数字不同的地方，会在条目里并列写出。结直肠癌家族史里的部分国内数字引自一篇综述，不是指南原文，条目里也有说明。

工具不推荐任何保健品。基于习惯的触发条件（外卖和共餐对应幽门螺杆菌、睡眠不足、长时间看屏幕）都标为“可考虑”，并明确写出它们是推断或关联。

## 局限

- 规则由我依据上述来源整理，没有经过临床医生审核。
- 感染风险相关问题只用一个“风险较高”勾选项，具体定义见 USPSTF 页面。
- 职业规则只覆盖七类暴露：噪声、矽尘、铅、苯、甲醛、甲苯或二甲苯、高温。GBZ 188—2025 涵盖的远不止这些。
- 血糖规则以 BMI 25 作为超重界线。

## 声明

这是依据已发布指南的筛查参考，不是诊断，也不能替代医生的建议。
